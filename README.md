# Job List Page

## 📝 Project Overview
**Job List Page** is a simple and responsive web page that displays a list of available job openings.  
Each job card presents essential details such as position title, company name, location, and a short description.  
This project is designed to showcase job listings in a clean and modern layout and can be easily expanded into a more complete hiring or recruitment system in the future.

The folder structure is kept simple for readability and easy maintenance.  
The `css` folder contains the styling files, `js` handles interactivity such as button actions or filtering, and `img` stores visual assets and icons.

---

## ⚙️ Tech Stack Used
- **HTML5** – Core structure of the webpage  
- **CSS3** – Styling, layout, and responsive design  
- **JavaScript** – Adds basic interactivity and dynamic elements  
- **GitHub Pages / Vercel** – For deployment and static hosting
